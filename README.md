# SiteTrack Pro – Construction CRM & Project Management System

A custom-built Construction CRM and Project Management System developed using Laravel, PHP, MySQL, and Bootstrap.

SiteTrack Pro helps construction businesses manage projects, daily site activities, labour, materials, vendors, budgets, and project progress through a centralized web application.

## Key Features

- **Project Management:** Manage projects, clients, budgets, engineers, and timelines.
- **BOQ Tracker:** Track work quantities, costs, and completion percentages.
- **Daily Work Tracking:** Monitor site activities, progress, and work status.
- **Labour Management:** Track workers, attendance, shifts, and labour costs.
- **Material Management:** Manage inventory, material requests, and quotations.
- **Vendor & Subcontractor Management:** Track work orders, invoices, payments, and balances.
- **Issue Tracking:** Manage site issues, priorities, assignments, and resolutions.
- **QMS Reports:** Generate downloadable project progress and quality reports.
- **Roles & Permissions:** Control user access and responsibilities.

## Technologies Used

- **Backend:** PHP, Laravel
- **Database:** MySQL
- **Frontend:** HTML5, CSS3, JavaScript, jQuery, Bootstrap
- **Architecture:** MVC
